# CharityChain – Blockchain-Based Charity Donation DApp

## 1. Project Overview

CharityChain is a decentralized charity donation application developed using React, Solidity, Ethereum-compatible blockchain technology, and MetaMask. It enables users to create charity campaigns, view campaign details, donate cryptocurrency, and maintain transparent on-chain donation records.

The project runs locally on a Hardhat development blockchain and is intended for educational and demonstration purposes.

## 2. Features

- Connect a wallet using MetaMask.
- Create charity campaigns with a title, description, and target amount.
- View all available charity campaigns.
- Donate ETH to active campaigns.
- Track the total amount raised by each campaign.
- View campaign status and creator address.
- Record donations and transactions on the blockchain.
- Allow campaign creators to manage campaign status and withdraw funds.

## 3. Technology Stack

- **Frontend:** React, Vite, JavaScript, CSS
- **Blockchain:** Ethereum-compatible local blockchain
- **Smart Contracts:** Solidity
- **Development Environment:** Hardhat
- **Wallet:** MetaMask
- **Blockchain Interaction:** Ethers.js
- **Smart Contract Compilation and Deployment:** Hardhat

## 4. Prerequisites

Install the following before running the project:

- Node.js and npm
- Visual Studio Code (or another code editor)
- MetaMask browser extension

## 5. Installation and Execution

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd charity-dapp
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the URL of your GitHub repository.

### Step 2: Install dependencies

```bash
npm install
```

### Step 3: Start the local Hardhat blockchain

Open a terminal in the project directory and run:

```bash
npx hardhat node
```

Keep this terminal running. Hardhat displays local test accounts and the RPC URL, normally `http://127.0.0.1:8545`.

### Step 4: Deploy the smart contract

Open a second terminal in the project directory and run:

```bash
npx hardhat run scripts/deploy.cjs --network localhost
```

Check the terminal for the deployed `CharityDonation` contract address.

Update `CONTRACT_ADDRESS` in `src/contract.js` with the address printed by the deployment command.

**Important:** If you restart the local Hardhat blockchain, deploy the contract again and update the address if it changes.

### Step 5: Configure MetaMask

1. Open MetaMask.
2. Add or select the local Hardhat network.
3. Use the local RPC URL `http://127.0.0.1:8545`.
4. Set the chain ID to `31337`.
5. Import one of the test accounts displayed by the local Hardhat node, using its private key.

**Security:** Use only the test accounts and private keys generated by your own local Hardhat node. Never use real funds or publish private keys.

### Step 6: Start the frontend

Open a third terminal in the project directory and run:

```bash
npm run dev
```

Open the local URL shown by Vite, for example:

```text
http://localhost:5173
```

If Vite selects another port, use the URL printed in the terminal.

## 6. How to Use the Application

1. Open CharityChain in your browser.
2. Click **Connect Wallet** and approve the connection in MetaMask.
3. Create a campaign by entering its title, description, and target amount in ETH.
4. Confirm the transaction in MetaMask.
5. Click **Refresh Campaigns** to view the campaign.
6. Enter a donation amount and click **Donate**.
7. Confirm the transaction in MetaMask.
8. Check the updated total raised and transaction activity.

The campaign creator can also manage the campaign status and withdraw funds using the corresponding contract functions.

## 7. Smart Contract Functions

| Function | Purpose |
|---|---|
| `createCampaign()` | Creates a new charity campaign |
| `getAllCampaigns()` | Retrieves all campaigns |
| `getCampaign()` | Retrieves one campaign |
| `donateToCampaign()` | Accepts a donation |
| `getDonationsByCampaign()` | Retrieves donation records |
| `setCampaignStatus()` | Activates or deactivates a campaign |
| `withdrawFunds()` | Allows the campaign creator to withdraw raised funds |

## 8. Limitations

- The application is configured for local blockchain development and testing.
- Local blockchain data is not a permanent public donation record.
- Campaign information and transactions depend on the deployed smart contract.
- The project has not been presented as a production-ready charitable payment platform.
